# commerce — standalone D1 store API

Small e-commerce read/write API backed by D1 (orders, products, inventory, audit log).

## Routes

| Method | Path | Description |
|--------|------|-------------|
| GET | `/health` | Liveness |
| GET | `/stats` | Row counts |
| GET | `/products?limit=20` | Product catalog with inventory |
| GET | `/orders/:id` | Order detail + line items |
| POST | `/orders` | Place order (`customer_id`, `items[]`) |

## Local deploy

```bash
./dev/scripts/reset.sh
./dev/scripts/up.sh
./dev/scripts/seed-commerce-store.sh
curl http://127.0.0.1:8787/commerce-store/v1/stats
```

Seed data is generated by `seed.sh` (default 80 products · 200 customers · 400 orders).
