# R2

R2 is object storage from the Worker (`env.BUCKET.put` / `get`). Objects live on **RustFS** under the version’s prefix.

## Branching

Child versions get an **overlay**: they read through to the parent, write locally, and use tombstones for deletes. Preview uploads do not mutate production objects.

## Worker

```js
await env.ASSETS.put('notes/hello.txt', 'hi')
const obj = await env.ASSETS.get('notes/hello.txt')
```

Declare `r2_buckets` in wrangler.

## Dashboard

R2 shows up on `GET …/bindings` and as a **badge**. There is **no object browser** — celld has no `r2` operator CLI yet, and cellp will not fake one.

To inspect objects, use the Worker, a one-off script, or the RustFS console in development.

## Not Cloudflare R2

The S3 implementation in a cellp deployment is **RustFS**. Do not point celld at AWS S3 or Cloudflare R2 for platform storage. Your *application* may call whatever HTTP APIs it wants from inside the isolate; the **platform** buckets stay private.
